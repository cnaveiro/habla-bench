Method

Every response is scored by deterministic checks only: JSON shape, word limits, bullet counts, forbidden words, voseo markers, peninsular Spanish markers, a Spanish-language heuristic, and numbers that do not appear in the provided context. No model is used as a judge.

Limitations

  • The language check is a word-frequency heuristic, not a full language detector.
  • no_invented_numbers covers digits only; spelled-out numbers are outside its scope.
  • Template-style checks reward format compliance, not truthfulness or usefulness.
  • Cost is an estimate based on provider token usage and the example prices in prices.yaml.
